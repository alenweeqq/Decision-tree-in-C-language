### Реализация дерева решений с бэггингом на C
---------------------------------------------------


Проект представляет собой реализацию алгоритма Random Forest на языке C без использования сторонних библиотек машинного обучения.

В основе проекта лежат:

* дерево решений (Decision Tree);
* ансамблевый метод Bagging;
* случайная подвыборка признаков (Random Feature Selection).

Программа поддерживает:

* классификацию;
* регрессию;
* визуализацию дерева;
* сохранение модели;
* экспорт дерева в PNG.

Обучение выполняется на CSV-датасете.

##

### - Дерево решений (Decision Tree)

Основой проекта является дерево решений.

Дерево состоит из:

* узлов;
* листьев.

В каждом узле выполняется проверка условия:

```text id="cv4t8i"
X[i] < threshold
```

где:

* X[i] — значение признака;
* threshold — порог разделения.

Если условие истинно — выполняется переход в левое поддерево, иначе — в правое.

Лист дерева содержит:

* класс объекта (для классификации);
* числовое значение (для регрессии).

Для построения дерева используется рекурсия.

##

### - DFS

Для обхода дерева используется DFS (обход в глубину).

DFS применяется:

* при предсказании;
* при визуализации дерева;
* при сохранении дерева;
* при освобождении памяти;
* при экспорте дерева в PNG.

##

### - Gini

Для выбора лучшего разделения в задаче классификации используется коэффициент Джини.

$$
\text{Gini} = 1 - \sum_{i=1}^{K} p_i^2
$$

где:

* $p_i$ — вероятность класса;
* $K$ — количество классов.

Чем меньше значение коэффициента Джини, тем лучше разделение.

##

### - Entropy

Дополнительно поддерживается критерий энтропии.

$$
\text{Entropy} = -\sum_{i=1}^{K} p_i \log_2 p_i
$$

Энтропия показывает степень неопределённости данных.

При построении дерева используется прирост информации (Information Gain).

##

### - MSE

Для задачи регрессии используется среднеквадратичная ошибка.

$$
\text{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y_i})^2
$$

где:

* $y_i$ — настоящее значение;
* $\hat{y_i}$ — предсказание модели;
* $n$ — количество объектов.

Чем меньше значение MSE, тем лучше качество модели.

##

### - Bagging

Для каждого дерева создаётся случайная подвыборка датасета с возвращением.

Алгоритм:

* случайным образом выбираются объекты;
* создаётся отдельный набор данных;
* обучается отдельное дерево.

Bagging позволяет:

* уменьшить переобучение;
* повысить устойчивость модели;
* улучшить качество ансамбля.

##

### - Случайная подвыборка признаков (Random Feature Selection)

При построении каждого узла выбирается случайное подмножество признаков.

Из выбранных признаков определяется лучший для разделения.

Использование случайных признаков:

* увеличивает разнообразие деревьев;
* уменьшает корреляцию между деревьями;
* повышает качество Random Forest.

##

### - Голосование

В задаче классификации каждое дерево независимо предсказывает класс.

Итоговый результат определяется большинством голосов.

Алгоритм:

* каждое дерево возвращает класс;
* подсчитывается количество голосов;
* выбирается класс с максимальным числом голосов.

##

### - Усреднение в регрессии

В задаче регрессии итоговый ответ вычисляется как среднее значение предсказаний всех деревьев.

$$
\hat{y} = \frac{1}{T} \sum_{i=1}^{T} y_i
$$

где:

* $T$ — количество деревьев;
* $y_i$ — предсказание дерева.

##

### - Bootstrap

Для обучения каждого дерева используется Bootstrap Sampling — случайная выборка объектов с возвращением.

Особенности:

* объекты выбираются случайно;
* выбор выполняется с возвращением;
* один объект может встретиться несколько раз;
* часть объектов может не попасть в выборку.

Bootstrap позволяет создавать разные деревья внутри ансамбля.

##

### - Визуализация дерева

Проект поддерживает:

* ASCII-визуализацию;
* экспорт дерева в PNG.

ASCII-визуализация выводится в консоль.

PNG-визуализация создаётся через Graphviz:

* генерируется файл `.dot`;
* выполняется преобразование в `.png`.

##

### Запуск программы

Пример запуска классификации:

```text id="r1i2e5"
./random_forest.exe dataset.csv 10 8 4 2 0.4 classification gini
```

Пример запуска регрессии:

```text id="v9f0d2"
./random_forest.exe dataset.csv 20 10 4 3 0.3 regression
```
