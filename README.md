### Реализация дерева решений с бэггингом на C

Проект представляет собой реализацию алгоритма Random Forest на языке C без использования сторонних библиотек машинного обучения.

В основе проекта лежит алгоритм дерева решений, дополненный:

- бэггингом (Bagging);
- случайной подвыборкой признаков (Random Feature Selection).

Программа обучается на CSV-датасете и выполняет классификацию объектов по признакам.
##
### - Дерево решений (Decision Tree)

Основой проекта является дерево решений.

Дерево состоит из:
- узлов;
- листьев.

В каждом узле выполняется проверка условия: X[i] < threshold

где:
- X[i] — значение признака;
- threshold — порог разделения.

Если условие истинно — выполняется переход в левое поддерево, иначе — в правое. Лист дерева содержит итоговый класс.



### -  DFS 

Для обхода дерева используется DFS (обход в глубину).

DFS применяется:
- при предсказании;
- при визуализации дерева;
- при сохранении дерева;
- при освобождении памяти.

  ### - Gini 

Для выбора лучшего разделения используется коэффициент Джини.

$$
\text{Gini} = 1 - \sum_{i=1}^{K} p_i^2
$$

где:

- pᵢ²    — вероятность класса;
- K — количество классов.

Чем меньше значение коэффициента, тем лучше разделение.

### - Bagging

Для каждого дерева создаётся случайная подвыборка датасета с возвращением.

Алгоритм:
- случайным образом выбираются объекты;
- создаётся отдельный набор данных;
- обучается отдельное дерево.

Bagging позволяет:
- уменьшить переобучение;
- повысить устойчивость модели.

### - Случайная подвыборка признаков (Random Feature Selection)

При построении каждого узла выбирается случайное подмножество признаков.

Из выбранных признаков определяется лучший для разделения.

Использование случайных признаков:
- увеличивает разнообразие деревьев;
- уменьшает корреляцию между деревьями;
- улучшает качество ансамбля.

### - Голосование

Каждое дерево предсказывает класс независимо.

Итоговое решение определяется большинством голосов.

### main.c
Главный файл программы.

Содержит:
- запуск программы;
- обработку аргументов командной строки;
- обучение модели;
- сохранение модели;
- вывод результатов.

Основные действия программы:

- загрузка датасета;
- разделение train/test;
- обучение Random Forest;
- вычисление accuracy;
- вывод предсказаний;
- визуализация дерева;
- сохранение модели.

### dataset.h / dataset.c

Модуль работы с датасетом.

Содержит:
- структуру Dataset;
- загрузку CSV-файлов;
- разделение train/test;
- освобождение памяти.

Используемые алгоритмы:

- чтение CSV;
- случайное перемешивание/ алгоритм Фишера–Йетса;
- случайное разделение выборки.

Основные функции:

- load_dataset() - загрузка датасета

Модуль дерева решений.

Содержит:
- структуру Node_Tree;
- построение дерева;
- предсказание;
- визуализацию;
- сохранение дерева.

Используемые алгоритмы:
- рекурсия;
- DFS;
- Gini;
- поиск лучшего разделения.

Основные функции:
- build_tree() - рекрсивное построение дерева

- print_tree() - визуализация дерева
- save_tree() - сохранение дерева в отдельный файл

Содержит:

- обучение ансамбля;

Используемые алгоритмы:

##
### Запуск программы

Пример запуска:

./random_forest.exe dataset.csv 10 8 4 2 0.4

Параметр -	Описание
- dataset.csv	- путь к датасету
- 10 -	количество деревьев
- 8	- максимальная глубина
- 4	- минимальное количество объектов
- 2	- количество случайных признаков
- 0.4	- размер тестовой выборки

- визуализирует дерево;
